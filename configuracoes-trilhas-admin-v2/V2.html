Configurações — Trilhas Adaptativas

Ajuste como as trilhas de revisão são geradas para os estudantes. Qualquer mudança só vale a partir do próximo ciclo — o que já está em andamento não é afetado.

Sensibilidade do diagnóstico

Configurações avançadas — Pesos e faixas do diagnóstico
O diagnóstico calcula um índice de dificuldade por habilidade combinando sete fatores. Cada fator tem um peso percentual. A soma de todos os pesos deve ser exatamente 100%.
Total: 100% Corrija para que a soma seja 100% antes de salvar.
Limites entre as faixas de urgência
Os valores devem ser Urgente > Moderada > Atenção.
Padrão: Urgente = 70 · Moderada = 50 · Atenção = 30

Agendamento
Quando o sistema processa os ciclos e gera as trilhas
Horário de geração das trilhas
Todo dia nesse horário (fuso de Brasília), o sistema verifica quais turmas têm ciclo encerrando e gera as trilhas de revisão para os próximos dias.
Padrão: 02:00
horário de Brasília (GMT-03:00)
Escolha um horário em que a plataforma é pouco usada pelos estudantes. O horário padrão (02:00) foi definido para minimizar impacto no desempenho.
Revisão pelo professor antes de publicar
Permite que o professor aprove cada trilha antes de ela chegar ao estudante
Exigir aprovação do professor
Quando ativado, cada trilha gerada fica aguardando revisão do professor antes de ser enviada ao estudante. Quando desativado, as trilhas são publicadas automaticamente.
Publicação automática
As trilhas serão publicadas automaticamente após a geração, sem necessidade de aprovação manual.
Prazo para o professor revisar
Depois de gerada, a trilha fica aguardando revisão por esse período. Se o professor não agir dentro do prazo, ela é publicada automaticamente.
Padrão: 72h
1 dia 7 dias
72h
